# 🚀 DEV-CORE STUDIO CLICKER — Архитектура и Механики Игры

Добро пожаловать в документацию игровой механики **Dev-Core Studio Clicker**. В данном документе описаны все реализованные фичи, экономика, таймеры и структура интерфейса.

---

## 📊 Основные Шкалы и Метрики (HUD)

1. **Шкала строк кода (LoC / Общие очки):**
   - Отображает общее количество написанных строк кода разработчиками и игроком.
   - Увеличивается при кликах по кнопке «КОДИТЬ» и автоматически за счет работы менеджеров.
   - Содержит анимированный мини-прогресс-бар текущего прогресса.

2. **Шкала бюджета и доходов (Деньги):**
   - Накапливает средства от монетизации готового IT-продукта.
   - **Таймер выплаты:** Каждые **30 секунд** (полминуты) происходит автоматическая выплата доходов на основе количества аналитиков и активных буффов.
   - Отображает таймер обратного отсчета до следующей выплаты в виде прогресс-бара.

3. **Шкала ускорения команды:**
   - Заполняется при активном кликании по кнопке ускорения (+2.5% за клик, до 100%).
   - Постепенно убывает со временем (скорость затухания зависит от количества бэкендеров).
   - Дает бонус к количеству строк за клик.
   - **Штраф за выгорание:** Если ускорение превышает **80%**, срабатывает предупреждение о выгорании (`🔥 ВЫГОРАНИЕ`), и доход продукта по таймеру временно снижается (если не нанят сисадмин).

## 🛍️ Магазины и Экономика

Интерфейс разделен на две независимые вкладки, прижатые к левой стороне экрана и не перекрывающие центральную кнопку и всплывающие эффекты:

### 1. 👨‍💻 Шоп Найм Сотрудников
Позволяет нанимать персонал с прогрессивной стоимостью (`база * 1.15^level`):
- **Разработчик (👨‍💻):** Увеличивает количество строк кода за каждый клик.
- **Аналитик (📊):** Увеличивает регулярный пассивный доход продукта.
- **Бэкендер (⚙️):** Стабилизирует сервер и замедляет затухание ускорения команды.
- **Менеджер (👔):** Автоматически пишет код в фоновом режиме.

### 2. 📜 Шоп Грамоты и Бонусы
Содержит награды, мотивацию и спецоперации для команды:
- **Почетная грамота (📜):** Перманентный множитель строк кода **x1.5**.
- **Бесплатное "Спасибо" (🙏):** Бесплатная кнопка поднятия морали с праздничным салютом.
- **Пицца для команды (🍕):** Удваивает производительность кодинга на 30 секунд.
- **Энергетик (⚡):** Мгновенный рывок ускорения команды (+35%).
- **Печеньки в офисе (🍪):** Увеличивает доход аналитиков.
- **Дежурный сисадмин (🛡️):** Смягчает штрафы от выгорания команды.

## 🎨 Особенности Интерфейса и UX

- **Центральная кнопка:** Интерактивная кнопка «КОДИТЬ» с кибернетическими вращающимися кольцами и эффектом пульсации расположена строго по центру экрана.
- **Всплывающие уведомления:** Все уведомления о покупке грамот, пиццы и благодарностей появляются на верхней трети экрана (`y: window.innerHeight / 3`), не сливаясь с центральной кнопкой кликера.
- **Атмосферный фон (WarpCanvas):** Динамические звездные варп-треки, ускоряющиеся при повышении комбо-множителя (Джун -> Мидл -> Сеньор -> Лид -> Архитектор -> CTO).
